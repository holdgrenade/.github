# .github

The profile of the [Grenade](https://www.holdgrenade.com) organization on GitHub, and the files every Grenade repository shares.

- [`profile/README.md`](./profile/README.md) is the page shown at [github.com/holdgrenade](https://github.com/holdgrenade).
- [`SECURITY.md`](./SECURITY.md) and the issue form in [`.github/ISSUE_TEMPLATE`](./.github/ISSUE_TEMPLATE) apply to every repository in the organization that has none of its own.
